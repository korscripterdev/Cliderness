*Песочница выживания в открытом мире* — автор: **korscripterdev**

Cliderness — свободная песочница выживания, нарисованная только символами CP437 в 16 цветах VGA на сетке 80×25. Один движок на ISO C90 работает в MS-DOS, FreeDOS, Windows, Linux, macOS и других Unix. Ни сюжета, ни финала: исследуйте, добывайте, стройте, меняйте ландшафт и выживайте.

## Что работает в 0.1.0

* Детерминированный 3D-мир по сиду (одинаковый в 16 и 64 битах), 38 биомов, пещеры, руды, океаны и рифы; сохраняются только изменённые чанки.
* Ходьба, бег, приседание, плавание, подъём, падение; добыча, установка, копание вниз и строительство вверх; инструменты с прочностью.
* Здоровье, силы, голод, жажда, усталость, температура тела; инвентарь на 36 ячеек с панелью быстрого доступа, предметы плавают или тонут.
* Игровое время со сменой сезонов и фаз луны, 18 видов погоды, обзор неба (солнце, луна, созвездия, облака, птицы, метеоры, сияние, затмения).
* **71** действительно работающая команда (права, дополнение по Tab, история, отмена/повтор).
* Офлайн-справка: 45 тем и 5 уровней, интерфейс на 11 языках; F1 / Esc полностью останавливают игру; надёжное сохранение (временный файл + CRC).

Пока нет: ремесла, существ и боя, текущей воды, кораблей, Древнего измерения и живого PCM-звука. Точный статус — в [ROADMAP.md](ROADMAP.md).

## Сборка

```sh
cmake -S . -B build && cmake --build build && ctest --test-dir build
make && make test
sh builds/dos/build_watcom.sh 16
```

Запустите `build/cliderness`. `--help` показывает параметры, `--version` — версию и автора.

## Управление (по умолчанию)

`WASD` движение · `Shift` бег · `Ctrl`/`X` присесть · `F` добыть · `R` поставить · `>`/`<` вниз/вверх · `E` подобрать · `U` использовать · `Tab` инвентарь · `C` персонаж · `правый Shift`/`V` небо · `F1`/`?` справка · `Esc` пауза · `/` консоль. Все клавиши можно переназначить.
